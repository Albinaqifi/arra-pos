# S-031 — Product, table and waiter reports

**State:** In progress; [PR #36](https://github.com/Albinaqifi/arra-pos/pull/36) awaits review and merge. The original base was `c4f45c7`; the branch now incorporates main through S-028.

The desktop report filters paid bills by an inclusive local date range and the authenticated administrator's financial scope in trusted code. It aggregates bill-line quantities and values by stable product ID, displaying the latest paid snapshot name in the period. Table counts use the order's current table and waiter counts use the payment-recording actor. These definitions, including moved-table and multi-waiter limitations, are labeled provisional. Unpaid orders are excluded because shared operational visibility is unresolved. Corrected payments use their effective account and count once. The owner has stated that no refunds should occur.
