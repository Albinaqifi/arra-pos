# S-031 — Product, table and waiter reports

**State:** In progress; review and testing passed, awaiting PR and merge. Base: `c4f45c7` (`main`).

The desktop report filters paid bills by an inclusive local date range and the authenticated administrator's financial scope in trusted code. It aggregates bill-line quantities and values by stable product ID, displaying the latest paid snapshot name in the period. Table counts use the order's current table and waiter counts use the payment-recording actor. These definitions, including moved-table and multi-waiter limitations, are labeled provisional. Unpaid orders are excluded because shared operational visibility is unresolved. Account corrections and refunds are not implemented yet (S-027/S-029); revisit this report when those stories land.
