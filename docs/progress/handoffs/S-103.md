# S-103 — Windows desktop shortcut for restaurant RC4

In progress, based on RC4 release commit `8141168`. Place **Arra POS.exe** beside **Open-Arra-Pay.cmd** in the extracted restaurant RC4 folder. Open the EXE, enter the existing PF700 settings, enable live checkout, and select **Save and create shortcut**. That completes setup without starting a sale or the receipt worker. Open the **Arra POS** desktop icon for daily checkout. To change printer details, reopen the EXE in the RC4 folder.

The native launcher uses Windows DPAPI for the original Windows account, checks the RC4 program and enrolled printer, and passes the settings over the existing private input pipe. It does not change the restaurant database or RC4 program. An existing unrelated desktop shortcut is preserved. The app reports the new link's name if Windows needs a different name.
