# S-076 — Sample-only Windows installer

**State:** In progress; base `a47ec6ade73832159ca8e44631ee1f099be19c35`. Review and checks passed; PR pending.

**Change:** Pinned Electron 45.2.1 (bundled Node 24.22.1 and SQLite) is packaged with the built renderer and desktop code into a versioned offline ZIP installer bundle. The installer writes versioned application files and Start menu shortcuts; setup prompts for sample credentials and seeds sample tables and menu in a separately marked AppData directory. Existing data is not intentionally replaced. This is sample-only; S-036, S-032 and S-051 remain outstanding.

**Builder checks:** Electron runtime run as Node successfully loaded `node:sqlite`. `npm run build:sample-installer` passed and produced `build/sample-installer/Arra-POS-Sample-1.0.0-Setup.zip`; its renderer build and architecture gate passed. The install script from the same payload, with APPDATA and LOCALAPPDATA redirected under `build/installer-check`, installed the runtime and shortcuts; a repeated install refused the existing version and preserved a sentinel in the sample-data directory. IExpress attempts failed to produce an EXE, so the artifact is a ZIP containing `install.cmd`. `git diff --check` reports pre-existing whitespace in unrelated `1 pije 2 ushqim.txt`; story-only whitespace check still needed.

**Review fix:** A shortcut failure previously stranded the new program version. The installer now prepares shortcuts in a temporary directory, publishes into a version-specific Start menu folder, and removes its newly published program directory if shortcut publication fails. An isolated test deliberately occupied the shortcut destination, confirmed the failure removed the new program directory while preserving pre-existing shortcut, sample-data and older-version sentinels, then removed the test obstruction and successfully retried. If cleanup itself fails, the error identifies the new directory to move aside. An abrupt interruption is not yet tested.

**Installed setup fix:** The owner reported the installed setup shortcut rejected its console because Electron's Windows executable did not expose TTY handles. Windows PowerShell now collects hidden input and sends it over a UTF-8 pipe to Electron; validation occurs before directory creation and existing directories are refused. `node --test tests/installed-sample-setup.test.js` passed 1/1 using the bundled Electron, including invalid input, sample credentials, seeded tables/menu, and refusal to replace an existing directory. A Windows PowerShell 5.1 check against an extracted bundle, with generated input substituted for interactive Read-Host, created a sample database through the packaged setup and Electron pipe. A real interactive shortcut check is still needed. The new bundle is version 1.0.1 so it can be installed alongside 1.0.0 without touching its files or sample data.
