# S-002 — Set up the local database

**State:** In progress; acceptance, review and testing passed locally; awaiting PR and merge. Base: `e694f41` (S-001 merge).

The Electron main process opens `arra.sqlite` in its user-data folder before creating the window. SQLite migrations are versioned with `user_version` and run in a transaction; a newer schema or failed migration stops startup with an error dialog. The database is closed on quit. The browser demo and renderer are not connected to it. README describes the location, development limitations and tests.

**Builder checks:** `npm test` passed all 5 tests: fresh creation and reopen, upgrade from version 1 with existing data, failed upgrade rollback, newer version rejection and inaccessible location. `node --check src/desktop/main.js`, `node --check src/desktop/database.js`, and `git diff --check` passed. `ELECTRON_RUN_AS_NODE=1` with Electron's binary confirmed its embedded Node 24.22.1 exposes `node:sqlite`; SQLite currently emits Node's experimental-feature warning.

**Review:** Independent reviewer approved the complete change, including untracked files, with no actionable findings. Review covered transaction handling, version compatibility, startup failure handling and preservation of user data.

**Tester:** Independently ran `npm test` on Node v24.13.0: all 5 tests passed; SQLite emitted its experimental warning. An isolated Electron launch in the sandbox exited with `0x80000003` before creating a database or window. Outside the sandbox the test process stayed running, but no database appeared in the intended temporary app-data directory and no separate window was observed; its data location could not be confirmed. The tester stopped only that test process and did not control the existing window.

**Desktop restart:** The user opened and closed the app. The coordinator inserted a labeled sample metadata row into the actual app-data database, the user reopened and closed the app, and the coordinator verified the row and schema version 2 remained. The sample row was then removed.

**Startup error:** The independent tester launched the actual desktop startup through a disposable wrapper that selected an isolated data directory containing a synthetic invalid database. A useful error dialog appeared, the test app exited after dismissal, and the invalid file remained unchanged. The wrapper and test data were removed.

**Outstanding:** PR and merge remain. No production use; UI persistence belongs to later stories.
