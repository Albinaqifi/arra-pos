## Closed-document journal check

Prepared `build/sample-installer/Arra-PF700-Journal-Check.zip` for an operator-assisted, read-only check of an already reconciled last document on COM3. Its README describes the confirmations, the risk of replacing the last response, and local-only text comparisons. The supported launcher requires operator attestation before opening the port; it cannot independently establish that all previous transactions are resolved. Its serial helper accepts only the fixed read-command sequence, and the reader bounds the journal scan. It does not read open receipts, verify recovery or save receipt text.

`node --test tests/pf700-journal-check.test.js` passed 5 tests; source review found no required issues in the supported diagnostic flow.
