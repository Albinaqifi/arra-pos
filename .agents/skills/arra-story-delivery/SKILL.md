# Arra POS story delivery

Follow `AGENTS.md` and `docs/process/workflow.md` for the requested story. Once the required review and checks pass, commit the story changes, push a story branch, and open a pull request when repository access permits. The owner has authorized these actions for Arra POS stories. Preserve unrelated work and report actual results. Mark a story Done only after its PR is merged; do not merge or rewrite history without explicit authorization.
